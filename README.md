## 🧠 Smart Money Concepts (SMC) Sneak Peek

<details>
<summary><b>🔥 Click to expand: What is a Fair Value Gap (FVG)?</b></summary>
<br>

A **Fair Value Gap (FVG)** occurs when aggressive institutional market orders cause extreme price displacement in a single candle, leaving an inefficiency between the neighboring candle wicks.

1. **Candle 1:** The origin wick.
2. **Candle 2:** Massive institutional displacement body.
3. **Candle 3:** Third candle does **not** touch Candle 1's wick.

*The unfilled space between Candle 1's high and Candle 3's low represents imbalance. Price magnetically returns to fill this gap before continuing the primary institutional trend!*

</details>
